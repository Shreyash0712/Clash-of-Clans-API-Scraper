Just a simple scraper that fetches all the API and model data from https://developer.clashofclans.com/ and stores it in JSON files.

Maybe I'll use it someday to create an application, especially since the Clash devs mentioned a major update is coming to the APIs!

Feel free to clone and use this (it only works on a local machine due to bot protection), or just check out the `endpoints.json` and `models.json` files to see the data directly.

Enter your credentials in .env (check .env.example) and run the scraper.

```bash
pnpm install
pnpm scraper
```
